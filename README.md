# Diario Crochet

Una aplicación desarrollada en Dart para llevar el registro completo de mis proyectos de crochet, controlar materiales y calcular precios de venta.
<img width="300" height="400" alt="Screenshot_2026-10-23-12-51-43-46_ee7544693d6dae5f2dac46f324e85af5" src="https://github.com/user-attachments/assets/e6ed071c-6be0-4b54-8cd3-4da89dd616f8" />

## ¿Qué hace la aplicación?

* **Registro de materiales y compras:** Control de los materiales utilizados en cada proyecto y lista de materiales pendientes por comprar.
  <img width="300" height="350" alt="Screenshot_2026-10-23-12-51-24-83_ee7544693d6dae5f2dac46f324e85af5" src="https://github.com/user-attachments/assets/2afc0774-a85d-4919-a90c-1a265649eadd" />

* **Seguimiento del proceso:** Estado de cada labor (sin empezar, en proceso o finalizado), tiempo total invertido, patrón, precio.
  <img width="300" height="350" alt="Screenshot_2026-10-23-12-44-04-66_ee7544693d6dae5f2dac46f324e85af5" src="https://github.com/user-attachments/assets/0ae9f77e-dfdb-4665-8aa9-6660d6520130" />

* **Contador de vueltas:** Herramienta para llevar la cuenta de pasadas mientras se sigue el patrón.
  <img width="300" height="350" alt="Screenshot_2026-10-23-12-43-20-24_ee7544693d6dae5f2dac46f324e85af5" src="https://github.com/user-attachments/assets/9b51f8cf-124b-4371-b06d-9906665383be" />
  
* **Calculadora de precios:** Cálculo automático del coste final del proyecto según el tiempo y los materiales, pensado para saber cuánto cobrar exactamente al hacer encargos.
  <img width="300" height="350" alt="Screenshot_2026-10-23-12-51-33-71_ee7544693d6dae5f2dac46f324e85af5" src="https://github.com/user-attachments/assets/7b29fb34-8a7d-423b-a8fe-23f0d9103872" />
  <img width="300" height="350" alt="Screenshot_2026-10-23-12-51-36-95_ee7544693d6dae5f2dac46f324e85af5" src="https://github.com/user-attachments/assets/f67631a3-517d-48f5-a1f3-8472fb2e17d6" />

## Tecnologías

* **Lenguaje:** Dart
* **Entorno de desarrollo (IDE):** Visual Studio Code
  
## Sobre este proyecto

Desarrollé esta aplicación de forma autodidacta para resolver una necesidad personal de organización en mis labores de crochet, 
mientras ponía en práctica conceptos de estructuración de datos y lógica en Dart.
